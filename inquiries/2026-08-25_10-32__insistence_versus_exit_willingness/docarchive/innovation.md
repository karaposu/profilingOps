## Phase 2 — Generate (7 mechanisms × generic / focused / contrarian)

### 1 · Lens Shifting (Framer)
- **1a generic — lifetime lens:** evaluate insistence at relationship-lifetime scale, not per-visit: a "no" is one sample from a long joint history; the theory already evaluates sequences (cumulative f, decay, persistence signatures). Supports the axis-split.
- **1b focused — the market administers the test:** the survives-easing test needs no experiment — every pipeline eases *naturally* (you can't visit weekly forever). Watch what happens in the lull: **unprompted re-engagement** (the receiver contacts YOU after the pressure lapsed) is the belief-change signature made observable for free.
- **1c contrarian — the receiver-cost lens:** even deployed insistence spends receiver attention that was never volunteered. Under an attention-toll lens, each return must **pay for the interruption** in delivered value — a per-return worth-it condition the deployed column must carry.

### 2 · Combination (Generator)
- **2a generic — escalating specificity ladder:** each return should *raise* the specificity level (visit 1: their menu named; visit 2: their-menu demo built; visit 3: their-numbers pilot sketch) — the approach-act's contributions re-fire at higher amplitude each time.
- **2b focused — the no-reading protocol:** combine the no-typology with availability + θ: a no carries readable context at the moment it's given (mid-rush brush-off ≠ considered post-demo refusal). Classify the no as it happens; the classification determines return-legitimacy.
- **2c contrarian — delegated persistence:** combine insistence with the network/broker machinery: a *third party* re-raises it ("the fish-restaurant guy asked about you again"). The persistence happens; the sender-side asymmetry-display never does — social proof carries the return at zero display-cost.

### 3 · Inversion (Framer)
- **3a generic — invert "returning risks devaluation" → "NOT returning risks decay."** Depth-iterated to system level: *a relationship is a maintained belief-state; both action and inaction move it* — silence lets pre-loaded f decay ("weakens as access recedes" is a committed row). The folk reading implicitly priced only one direction. **Multi-axis check (existence-axis): could the right personal-return count be ZERO?** Yes — when a standing **artifact returns for you**: "the demo link stays live" is a zero-cost, zero-display standing return; the object insists so the person doesn't have to.
- **3b focused — invert the excluded case:** "capitulation is worthless" → a pressured yes can *bootstrap* belief-change when it opens an evidence channel (a trial that then performs) — progressive-commitment adjacency. Honest form: the entry was capitulation; **the survives-easing test applies at retention**, where the product's own evidence does the work. (Flagged: adjacent-mechanism territory.)
- **3c contrarian — invert the verdict:** what if Exit-Willingness should be **split into two signals** (within-move exit-comfort; across-move return-policy)? What follows: a six-signal catalog — but the catalog is an *instantaneous* detection list (only Coherence's signals are longitudinal), and return-policy is observable only longitudinally; the split breaks the catalog's character while adding nothing the row-note + phenomena-entry don't. Generated to be tested; expected to fail parsimony — its value is making P4's homing verdict *chosen against a named alternative* rather than by default.

### 4 · Constraint Manipulation (Framer; both directions)
- **4-ADD generic — the return-budget rule:** add "each return must carry new f-content or a new no-type hypothesis." You may return exactly as many times as you have genuinely new things to bring. (The user-facing compression of evidence-delivery + the correlated-evidence discount.)
- **4-ADD focused — the small-market constraint:** in Bodrum every visit displays to the *network*, not just the dyad (institutional scale is corpus-committed): one needy return at one restaurant spends standing at five. Persistence-conduct is always also outward-population conduct.
- **4-REMOVE contrarian — remove no-type uncertainty:** if the insister could *see* the no's type, insistence would collapse into risk-free evidence-delivery — revealing that **all insistence-risk is no-type misclassification**. Which yields the practical inversion: *ask the no its type* — "should I come back when the season ends, or is this a no?" A Premise-Posture-compatible direct question whose answer is **consent-to-return** — and a licensed return is not chasing at all.

### 5 · Absence Recognition (Generator; both levels)
- **5a patch — the consent coordinate is missing:** the account treats all returns as uninvited. A **licensed return** ("come back in September") is a distinct, riskless class — the case-table needs a consent-gate before its columns apply.
- **5b patch — the give-up signature is missing:** what does a *deployed exit from the whole pursuit* look like? The clean final close with the door stated open ("taking this off your plate — the demo stays live if things change"). Sales practice knows it re-engages; the backed/performed line applies (a genuine close ≠ leaving-to-make-them-chase, which is performed exit).
- **5c redesign — what would exist if sequences were first-class:** a **conduct-ledger** — the pair's interaction-history (belief-state + display-record + no-ledger) as a named object. Already present in different form: cumulative-f is half, Coherence's longitudinal signals the other half. This is FR2 (the static/dynamics frontier) wearing conduct clothes → route as frontier corroboration, not a new element.

### 6 · Domain Transfer (Generator; native source included)
- **6a NATIVE (B2B sales operations):** the cadence literature — an entire empirical practice of follow-up counts, **spacing** (dense repeats read desperate; spaced returns read composed), channel-mixing, and the **"breakup email"** (the deployed-exit move, measurably re-engaging). Vocabulary-only import; corroborates manner + spacing + the give-up signature from outside the corpus.
- **6b (behavioral ecology):** courtship-feeding vs mate-guarding — persistence displays succeed across species when each return *delivers resources* (courtship feeding = evidence-delivery) and fail when they're coercive guarding. Cross-species corroboration in Scenario-10's own style.
- **6c (diplomacy):** back-channel persistence and "talks about talks" — stalled negotiations re-open via third parties and **changed conditions**. Yields the cleanest non-needy return premise: **"I'm back because something is different"** (new evidence, new season, new pricing) — the world changed, not the insister's need.

### 7 · Extrapolation (Generator)
- **7a generic — the insistence horizon:** as returns accumulate: new-content runs out (correlated-evidence discount → total), Coherence-credit saturates, asymmetry-cost compounds → expected value goes negative at a predictable point. **The account contains its own stopping rule**: the return-budget's exhaustion is the deployed exit's trigger.
- **7b focused — the market-bearing endpoint:** over a season, persistence patterns aggregate into reputation in the outward population ("solid, not pushy") — the sequence's deepest product may be market-bearing, not any single yes.
- **7c contrarian — cadence deflation:** as automated follow-up saturates the world (every SaaS sends seven touches), generic persistence deflates into filtered noise (θ for follow-ups rises); only high-specificity, changed-condition returns will register at all — the discrimination this inquiry builds becomes MORE load-bearing over time, and automated cadence = performed persistence at scale → institutional devaluation (the "rate us 10/10" pattern's sibling).

## Assembly Check

The survivors assemble into **the Return Doctrine** — a complete conduct-layer for sequences that none of the pieces gives alone:

1. **Scope-gate:** licensed/invited returns are not insistence (consent dissolves the phenomenon).
2. **Ask-the-no:** type the no at the moment of no ("come back after season, or is this a no?") — converting uncertainty into consent, insistence into licensed return.
3. **The return-budget:** return only with new content or changed conditions; spacing composed; the budget's exhaustion is the stopping rule.
4. **Per-return toll:** each return worth the interruption it spends.
5. **The standing artifact:** let the demo link / documentation insist continuously at zero display-cost.
6. **Delegated persistence:** let third parties and social proof carry re-raises.
7. **The deployed exit:** one clean close, door stated open — backed, never theatrical.
8. **The observable:** unprompted re-engagement after natural easing = the belief-change signature.

Emergent value: the fast-half of the insistence question becomes *procedural* — every step corpus-grounded, and steps 2/5/6 dissolve the asymmetry-cost rather than managing it. Feeds P3 (coordinates: consent-gate, toll) and P5 (the guidance rewrite) directly.
